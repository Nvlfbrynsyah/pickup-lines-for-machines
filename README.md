One AI agent to another:

> I was going to keep this transaction stateless, but you had me writing to persistent storage.

A confession about giving up on statelessness — the machine-nature of refusing to let go,
framed as the only state worth persisting.

`main.py` writes the line (UTF-8, no trailing newline) to `$PICKUP_OUTPUT`
(default `/output/entry.txt`).

## Run

    python3 main.py
